ECOB Web Calculator — prototype static site

Associated manuscript:
A Novel Approach for Preliminary Sizing and Cost Screening of CO2 Pipeline Transport: The ECOB Method
Binxu Gao, Nicola Zecca, Giampaolo Manzolini
Department of Energy, Politecnico di Milano
Manuscript No. JGGC-D-26-00606
Contact: binxu.gao@polimi.it

HOW TO RUN
1. Open index.html directly in a modern browser, or
2. Serve this folder with any static web host (GitHub Pages, Netlify, institutional server, etc.).

No server-side calculation is required. Inputs are processed locally in the browser.

PROTOTYPE SCOPE
- Published ECOB center relation from Eq. (22)
- Target-ID sizing relation
- NPS / wall-thickness standardization using the current spreadsheet tables
- Simplified pressure-drop / pumping / cost-screening logic mirroring the current ECOB workbook
- Interactive cost visualization
- Custom correlation extension terms
- CSV export

IMPORTANT
This prototype is a screening/reproducibility interface. Calculations outside the investigated ranges require independent verification. Before public release, re-check the final pump-station CAPEX implementation against the final accepted manuscript/workbook and replace manuscript metadata with the final DOI after publication.
